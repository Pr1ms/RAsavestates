Game: Donkey Kong (GB)
Hash: Donkey Kong (World) (Rev 1) (SGB Enhanced).gb (4859ec2b18c4fabf489eb570c1d7d326)
Emulator: RALibretro 1.8
Core: Gambatte v0.5.0-netlink (77f2567)

The folder structure is the following:
/progression: progression achievements
/win: win condition achievement
/milestones: sets us up at the beginning of each World (except world 0 for which a new save is )

In this set, all progression/win achievements are boss stages. 
There are two main types of boss mechanics: 
- either we have to reach peach to win (intemerdiate bosses)
- or we have to hit the boss a certain number of times with a barrel

I've provided three savestates for each:
- XXX_stage_y_z: the view in the world when the next stage is the boss stage
- XXX_boss_nearly_beaten: we are really close to reaching peach or the boss only needs one more hit and we're set up barrel in hand in reach
- XXX_boss_beaten: a few frames after the actual unlock

NB: A unique mechanics exists for the very first boss where we need to walk on several blocks to make the boss fall. For this one I've set us up with one last block to walk on.
